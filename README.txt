BULLS YOUTH — LANDING PAGE
==========================

Files:
- index.html — 7-section one-page landing
- style.css — responsive layout, design system and animations
- script.js — mobile menu, scroll reveal and subtle hero interaction

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in a browser. For best results, use a local server such as VS Code Live Server.
3. Internet connection is needed for Google Fonts and the remote photo URLs.

BEFORE PUBLISHING
